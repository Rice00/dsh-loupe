三套浮窗气质，选一个

三套用的是同一套 DOM、同一段内容，只换 CSS 变量 —— 所以差异纯粹来自气质，不是结构。挑定之后我再动插件代码（现在没改）。也可以组合，例如「取 A 的底色 + C 的投影」。
